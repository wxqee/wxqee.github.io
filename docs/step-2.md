# 第二步：页面设计规范（现代 · 科技感 · 严肃专业）

目标：
- 以“现代、科技感、严肃专业”为基调完成首页设计规范
- 形成稳定的信息架构与视觉系统，方便第三步填充内容
- 全程信息脱敏，内容以占位与分级展示为主

## 品牌语调
- 气质：先锋、可信、效率优先
- 风格：深色优先、霓虹渐变、几何与网格
- 交互：快速、动效克制但有科技感、清晰可读

## 信息架构（IA）
- 导航：首页 / 关于 / 经历 / 技能 / 项目 / 联系
- 首页 Hero：一句话价值主张 + 行动按钮（了解我 / 获取联系）
- 关于：简短介绍与当前关注方向（脱敏）
- 经历：时间轴式卡片（岗位与核心职责概括，脱敏）
- 技能：分组标签（语言、框架、云与平台、方法论）
- 项目：若干项目卡片（目标、成果、关键技术，脱敏）
- 联系：公开渠道与合规说明

## 视觉系统（V2.0 - Dark Tech）
- **核心基调**：深邃、极简、高性能
- **色彩模式**：纯暗色背景 + 荧光点缀（Cyberpunk/Linear 风格）
  - 背景：`#050505`（近乎纯黑，带微弱噪点）
  - 主字：`#ededed`（高亮白）
  - 副字：`#888888`（中性灰）
  - 强调色：`#00f2ea`（青色）至 `#ff0055`（玫红）的渐变流光
- **排版**：
  - 字体：Inter / System UI，强调字重对比
  - 布局：大留白，非对称网格，卡片悬浮
- **装饰元素**：
  - 动态光晕（Glow effects）
  - 细微的边框高亮（Border gradients）
  - 磨砂玻璃（Backdrop blur）

## 组件与模式
- 按钮：primary / ghost（悬停高亮与发光边框）
- 卡片：边框 + 轻微悬浮，支持彩色描边
- 标签：圆角、低饱和背景
- 时间轴：左窄右宽，年份列 + 内容列
- 锚点导航：平滑滚动、焦点可见
- Hero 装饰：渐变几何图形与轻微动效

## 可访问性与性能
- 颜色对比满足 WCAG AA
- 键盘可达与焦点态
- 轻量无框架、零阻塞脚本
- 图片与图标走静态资源，按需加载
- 动效轻量且尊重“减少动效”系统偏好

## 脱敏与合规
- 简历来源信息只做概括，不含姓名、电话、邮箱等个人敏感项
- 经历与项目以职责与成果为主，避免公司与具体数据暴露
- 联系方式采用公共渠道（如 GitHub、LinkedIn、邮箱别名）

## 落地范围
- 更新样式系统（颜色变量、卡片、标签、时间轴）
- 重构首页结构为上述 IA（占位内容）
- 第三步将按此规范逐步填充脱敏内容
